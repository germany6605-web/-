# Рудокоп — версия для ВКонтакте и Одноклассников

Кликер про добычу руды, торговлю на бирже и переплавку слитков. Эта ветка —
перенос игры с Яндекс Игр на **VK Games** и **OK Games**. Одна сборка работает
на обеих платформах: нужная определяется автоматически по параметрам запуска.

## Что изменилось относительно версии для Яндекса

| Возможность | Яндекс Игры (было) | ВКонтакте | Одноклассники |
|---|---|---|---|
| SDK | `YaGames` | VK Bridge 3.0.2 (`lib/vk-bridge.min.js`) | OK FAPI (`api.ok.ru/js/fapi5.js`) |
| Облачное сохранение | `player.setData` | `VKWebAppStorageSet/Get` | REST `storage.set/get` |
| Реклама за награду | `showRewardedVideo` | `VKWebAppShowNativeAds` (`reward`) | `FAPI.UI.loadAd` + `showLoadedAd` |
| Покупки | `payments.purchase` | `VKWebAppShowOrderBox` (голоса) | `FAPI.UI.showPayment` (ОКи) |
| Рейтинг | лидерборды Яндекса | `VKWebAppShowLeaderBoardBox` (удары киркой) | приглашение друзей |
| Приглашение друзей | — | `VKWebAppShowInviteBox` | `FAPI.UI.showInvite` |
| Пауза | `game_api_pause` | `VKWebAppViewHide/Restore` + скрытие вкладки | скрытие вкладки |

Изменённые файлы: `platform.js` (переписан полностью), `products.js` (новый — цены),
`app.js` (рейтинг, цены в магазине), `i18n.js` (тексты без упоминаний Яндекса),
`index.html` (подключение скриптов). Игровая логика (`core.js`, `scene.js`,
`audio.js`, `style.css`, `assets/`) не менялась.

### Сохранения

Лимит VK — 4 КБ на ключ, поэтому сохранение режется на части (`ob_a0`, `ob_a1`, …)
и пишется поочерёдно в два слота (`a`/`b`). Указатель `ob_meta` обновляется последним,
так что прерванная запись не портит прогресс. Дополнительно прогресс хранится
в `localStorage` под ключом, привязанным к id игрока.

## Цены

Цены задаются в `products.js`: `vk` — в голосах (1 голос ≈ 7 ₽), `ok` — в ОКах
(1 ОК ≈ 1 ₽). Этот же файл читает сервер платежей, поэтому цены всегда совпадают.
Для OK названия (`id`) товаров должны совпадать с `product_code`.

## Сервер платежей (обязателен для покупок)

Обе соцсети проводят оплату только после подтверждения от вашего сервера.
Готовый сервер без зависимостей лежит в `server/server.js`: он проверяет подпись
запросов и заодно раздаёт файлы игры.

```bash
VK_SECRET=<защищённый ключ VK> OK_SECRET=<секретный ключ OK> PORT=8080 npm start
```

Серверу нужен HTTPS (например, nginx с сертификатом перед Node.js).

* **ВКонтакте** → настройки приложения → «Платежи» → адрес обратного вызова:
  `https://ваш-домен/payments/vk`
* **Одноклассники** → настройки приложения → «Callback URL»:
  `https://ваш-домен/payments/ok`

Номера заказов сервер хранит в памяти. Для боевого запуска замените их на базу данных
(места помечены комментариями).

## Публикация

### ВКонтакте
1. [vk.com/editapp?act=create](https://vk.com/editapp?act=create) → тип «Игра».
2. В «Настройках» укажите адрес iframe: `https://ваш-домен/` (VK сам добавит
   параметры `vk_app_id`, `vk_user_id`, `sign`…).
3. Включите «Нативную рекламу» (монетизация), платежи и тип рейтинга «очки».
4. Загрузите иконки и обложку и отправьте игру на модерацию.

### Одноклассники
1. [ok.ru/dk?st.cmd=appsInfoMyDevList](https://ok.ru/dk?st.cmd=appsInfoMyDevList) → «Добавить приложение» → тип «Игра».
2. Ссылка на приложение: `https://ваш-домен/`. OK передаёт `api_server`,
   `apiconnection`, `logged_user_id`.
3. Запросите у поддержки OK права на платежи и рекламу (`loadAd`), если они не выданы.
4. Укажите Callback URL для платежей (см. выше).

Архив со статикой для любого хостинга: `npm run build` → `dist/rudokop.zip`.

## Локальная проверка

```bash
npm start            # http://localhost:8080 — локальный режим, без рекламы и покупок
```

Режим платформы можно включить вручную: `?platform=vk` или `?platform=ok`
(вне соцсети SDK не ответит, и игра перейдёт в локальный режим).
