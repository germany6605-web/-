# Паркур Башня — 275 уровней

3D-паркур (обби) на Three.js для Яндекс Игр. Работает на ПК (клавиатура WASD/стрелки + пробел) и на телефоне (виртуальный джойстик + кнопка прыжка, свайп для камеры).

## Возможности

- 275 процедурно сгенерированных уровней в 11 тематических мирах (луга, пустыня, снег, лава, космос и т.д.)
- Несложный паркур: широкие платформы, короткие прыжки, прощающая физика (koyote time, буфер прыжка)
- Автоматическая точка сохранения на каждом уровне — прогресс сохраняется через SDK Яндекс Игр (или localStorage, если SDK недоступен)
- Единый билд без внешних зависимостей во время игры (все ресурсы собираются в `dist/`)

## Разработка

```bash
npm install
npm run dev        # локальный сервер разработки
npm run build       # сборка в dist/
npm run preview     # проверить собранный dist/ локально
npm run validate    # программная проверка проходимости всех 275 уровней
```

## Публикация в Яндекс Игры

1. `npm run build` — соберёт статичную игру в папку `dist/`.
2. Заархивируйте **содержимое** папки `dist/` (не саму папку) в ZIP.
3. В кабинете разработчика Яндекс Игр создайте новую игру (HTML5) и загрузите этот ZIP.
4. `index.html` уже подключает `https://yandex.ru/games/sdk/v2` и вызывает `ysdk.features.LoadingAPI.ready()` после загрузки, а прогресс сохраняется через `player.setData`/`getData`. Вне Яндекс Игр (например, при локальном тестировании) игра автоматически использует `localStorage`.

## Структура

- `src/levels.js` — детерминированный генератор уровней (по seed от номера уровня)
- `src/player.js` — физика игрока (гравитация, прыжок, коллизии, авто-подъём по ступенькам)
- `src/game.js` — стриминг уровней, чекпоинты, сохранение, победа
- `src/input.js`, `src/camera.js`, `src/ui.js` — управление, камера, интерфейс
